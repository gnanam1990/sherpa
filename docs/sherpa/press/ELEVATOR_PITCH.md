# Elevator Pitch

## 30-Second Pitch

> Sherpa is the natural-language operating system for DeFi on Base. Instead of navigating complex interfaces, users just type what they want — "send 5 USDC to vitalik.base.eth" or "swap 1 ETH for USDC" — and Sherpa executes it onchain with sponsored gas. Think Siri for DeFi.

## 60-Second Pitch

> DeFi is powerful but inaccessible. Users need to understand wallets, gas, slippage, protocols, and dozens of interfaces. Sherpa changes that.
>
> Sherpa is a natural-language DeFi agent on Base L2. Users type plain English commands and Sherpa handles everything — parsing the intent, selecting the best protocol, simulating the transaction, and executing onchain with sponsored gas.
>
> Built with 7 safety rings, Sherpa protects every transaction before it executes. Integrated with Aerodrome for swaps and Aave for lending/borrowing, Sherpa makes DeFi as easy as texting.
>
> Available on web, Farcaster, and Telegram.

## For Developers

> Sherpa is an open-source natural-language DeFi agent on Base L2. It parses English intents, validates through 7 safety rings, simulates via Tenderly, and executes onchain via Coinbase Smart Wallet with sponsored gas. Integrates with Aerodrome (DEX) and Aave V3 (lending). MIT licensed.
