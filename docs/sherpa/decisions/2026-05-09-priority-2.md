# Priority 2 design decisions

Date: 2026-05-09
Context: Priority 2 (limitless findMarket, Pyth quote tier, EIP-5792 batch test)

## 1. Limitless REST: best-guess + injectable
- Defaults are research-derived but unverified
- All URLs/params injectable via LimitlessConfig
- Real wiring is a one-file change when Limitless contact lands
- See packages/tools/src/limitless.ts createLimitless()

## 2. EIP-5792 BET test: factoryAddress in createLimitless
- Rejected vi.mock (tests fiction, not integration)
- Rejected env var (global state for test-only need)
- Chose config injection: production-safe, test-friendly
- Same mechanism for wiring real address later

## 3. Pyth depth: Hermes HTTPS, no SDK
- Tier order: Live RPC → Pyth Hermes → 3000 USDC stub
- Plain fetch() to hermes.pyth.network
- No SDK dep; matches existing fetch pattern in repo

## 4. findMarket inputs: predicate + optional rest
- predicate: required (today's parser provides)
- asset/threshold/deadline: optional (parser may extract later)
- Future-proof; no breaking change when parser learns more

## 5. assertAllowlisted second parameter (Priority 2 ripple)
- Adapters can vouch for their own factory address per-call via extras[]
- Default [] preserves all existing call site behavior
- Per-call only — no global mutation, no test polution
