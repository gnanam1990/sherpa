# Decision: DCA - Scheduled Buys (Stage 4 P1)

**Date:** 2026-05-15
**Status:** Accepted
**Stage:** 4 P1

## Context
Sherpa needs DCA (Dollar Cost Averaging) for automated recurring buys.

## Decisions

### Scheduling
- Hourly cron checks for due DCA schedules
- Supports daily, weekly, monthly frequencies
- Configurable day-of-week and day-of-month

### Pre-authorization
- User signs ONE pre-authorization at setup
- Per-tick approval (each DCA = one signature) for V1
- Session keys for Stage 5

### Failure Handling
- 3 consecutive failures = pause schedule
- User notified on each failure
- Manual resume via /api/dca/:id PATCH

## Future Work
- Session keys for zero-signature DCA
- DCA history dashboard
- Email/push notifications
