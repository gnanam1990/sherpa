# Devlog: Stage 8 P3 — Mobile & Cross-Chain UX

**Date:** 2026-05-15
**Stage:** 8 P3
**Author:** Sherpa

## What shipped

### Parser (core)
- `CROSS_CHAIN` intent with two deterministic patterns:
  - `bridge <amount> <asset> from <source> to <dest> and <action>` → multi-step cross-chain
  - `swap <amount> <asset> at/for <chain> for <target>` → single-chain cross swap
- Regex patterns in `parser.ts:150-152`
- Slots: `crossAmount`, `crossAsset`, `crossSource`, `crossDest`, `crossAction`, `crossChain`, `crossTarget`

### Cross-chain Router (tools)
- `findBestRoute(source, dest, amount, deps)` — stub returns Across route with 0.1% fee
- `estimateCrossChainTime(source, dest)` — 120s L2-to-L2, 600s L1-involved

### Mobile UX
- No parser changes needed; existing confirmation cards are responsive
- Bridge time estimates surfaced in transaction cards
- Multi-step progress indicators for cross-chain flows

### Tests
- `packages/core/src/index.test.ts` — 2 CROSS_CHAIN parser tests
- `packages/tools/src/cross-chain/router.test.ts` — 3 router tests (new file)
