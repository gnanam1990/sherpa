**Date:** 2026-05-15

## What shipped

### Parser (core)
- `DEVELOPER` intent with deterministic parsing for:
  - `create api key` → `devAction: 'create_key'`
  - `show api docs` → `devAction: 'docs'`
  - `check my api status` → `devAction: 'status'`
  - `create webhook for <event>` → `devAction: 'webhook'`
- Regex patterns in `parser.ts:144-148`
- Slots: `devAction`, `devEvent`

### SDK module (tools)
- **api-keys.ts**: `generateApiKey()`, `validateApiKey()`, `hashApiKey()`, `createApiKey()`
- **webhooks.ts**: `generateWebhookSecret()`, `createWebhook()`, `verifyWebhookSignature()`
- **client.ts**: `SherpaClient` class with `parse()`, `plan()`, `getBalance()`, `createWebhook()` methods
- **types.ts**: Full type definitions for SDK config, requests, responses, API keys, webhooks
