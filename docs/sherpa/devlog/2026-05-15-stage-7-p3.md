# Devlog: Stage 7 P3 — Social Features

**Date:** 2026-05-15
**Stage:** 7 P3
**Author:** Sherpa

## What shipped

### Parser (core)
- `SOCIAL` intent with deterministic parsing for:
  - `follow @alice` → `socialAction: 'follow', socialTarget: '@alice'`
  - `copy trade @bob` → `socialAction: 'copy_trade'`
  - `show leaderboard` → `socialAction: 'leaderboard'`
  - `view my profile` → `socialAction: 'profile'`
- Regex patterns in `parser.ts:127-130`
- Slots: `socialAction`, `socialTarget`

### Social tools
- `getProfile(address)` — returns `SocialUser` with followers, following, totalVolume, successRate, rank
- `getLeaderboard()` — returns ranked list of top traders
- `startCopyTrade`, `stopCopyTrade`, `getCopyTradeStatus` — copy trade lifecycle
- Types: `SocialUser`, `CopyTradeSettings`, `SocialDeps`
- Stub implementations for V1; all functions return deterministic mock data

### Tests
- `packages/core/src/index.test.ts` — 4 SOCIAL parser tests
- `packages/tools/src/social/profiles.test.ts` — 2 profile module tests
