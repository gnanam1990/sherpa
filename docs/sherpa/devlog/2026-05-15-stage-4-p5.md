# Devlog: Stage 4 P5 — AUTO_REBALANCE

**Date:** 2026-05-15
**Author:** Sherpa Core Team

## Summary

Implemented the AUTO_REBALANCE intent as part of Stage 4 P5. This adds portfolio rebalancing capabilities to the Sherpa agent.

## Changes

### packages/core/src/parser.ts
- Added `REBALANCE_RE` regex for generic rebalance commands
- Added `REBALANCE_TARGET_RE` regex for target-specific rebalance commands
- Added parsing logic in `parseDeterministic()`
- Added `'AUTO_REBALANCE'` to `VALID_INTENTS` array

### packages/core/src/types.ts
- Added `'AUTO_REBALANCE'` to `Intent` union type
- Added `AutoRebalancePlan` type with allocation tracking and rebalance actions

### packages/core/src/executor.ts
- Added `planAutoRebalance()` function returning a stub confirmation card
- Added dispatch in `plan()` function

### packages/safety/src/rings.ts
- Added `validateRebalance()` function with configurable max drift threshold (default 50%)

### packages/agentkit/src/errors.ts
- Added `AUTO_REBALANCE_ERRORS` constant with user-facing error messages

### packages/core/src/index.test.ts
- Added 4 test cases for AUTO_REBALANCE parsing:
  - `rebalance my portfolio`
  - `auto rebalance my holdings`
  - `rebalance so that ETH is 60%`
  - `rebalance to USDC equals 50`
