# Stage 5 P1 — Multi-chain Support

**Date:** 2026-05-15

## Summary
Added multi-chain token registries and L2-to-L2 bridge parsing tests.

## Changes

### Token Registry (`packages/tools/src/registry.ts`)
- Added Arbitrum (chainId 42161) token registry: USDC, ETH, WETH, ARB, USDT, WBTC
- Added Optimism (chainId 10) token registry: USDC, ETH, WETH, OP, USDT
- Updated `getTokensForChain()` to return tokens for Arbitrum and Optimism
- Updated `resolveToken()` to resolve tokens on all supported chains

### Tests (`packages/tools/src/registry.test.ts`)
- Added `multi-chain token resolution` test suite
- Tests for USDC resolution on Arbitrum and Optimism with correct addresses
- Tests for chain-specific tokens: ARB on Arbitrum, OP on Optimism
- Tests for `getTokensForChain()` returning correct counts per chain

### Parser Tests (`packages/core/src/index.test.ts`)
- Added `BRIDGE L2-to-L2` test suite
- Test for "bridge 100 USDC from base to arbitrum" parsing with sourceChain/destinationChain
- Test for "bridge 0.1 ETH optimism to arbitrum" parsing
