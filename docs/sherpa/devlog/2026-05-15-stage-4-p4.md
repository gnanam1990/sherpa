# Stage 4 P4: TIME_LOCK

**Date:** 2026-05-15

## What was built
- TIME_LOCK intent parser (2 regex patterns: SCHEDULE_RE, TIMELOCK_RE)
- Scheduled transaction type with slots: scheduledAction, scheduledAmount, scheduledAsset, scheduledRecipient, scheduledTime
- Time lock executor (planTimeLock)
- 5 parsing tests covering schedule send, time lock transfer, schedule swap, timelock shorthand, and case-insensitivity

## Key files
- packages/core/src/parser.ts (TIME_LOCK regex: SCHEDULE_RE, TIMELOCK_RE)
- packages/core/src/types.ts (TimeLock intent type)

- docs/sherpa/decisions/2026-05-15-timelock-stage-4.md

## Design notes
- SCHEDULE_RE: captures send/transfer with amount, asset, recipient, time (confidence 0.9)
- TIMELOCK_RE: generic catch-all for schedule/timelock + any action + time (confidence 0.85)
- Relative time parsing ("in 2 hours") for V1; absolute times deferred
