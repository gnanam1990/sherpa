# Stage 3 P2: Telegram Bot

**Date:** 2026-05-15

## What was built
- apps/telegram-bot standalone Node.js bot
- Grammy-based bot with /start, /help, /send, /balance, /history, /link
- Natural language intent parsing via Sherpa API
- Inline keyboard confirmation buttons
- One-time signing URL generation
- TG user → Smart Wallet linking
- Web signing page for TG flow
- DB migration for TG user links

## Key files
- apps/telegram-bot/ (new project)
- apps/api/src/routes/telegram.ts (signing endpoint)
- apps/web/app/sign/page.tsx (signing page)
