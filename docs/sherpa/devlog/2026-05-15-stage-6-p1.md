# Devlog: Stage 6 P1 — Portfolio Dashboard

**Date:** 2026-05-15
**Stage:** 6 P1
**Author:** Sherpa

## What shipped

### Parser (core)
- `PORTFOLIO` intent with deterministic parsing for:
  - `show my portfolio` → `portfolioAction: 'show'`
  - `check portfolio on <chain>` → `portfolioAction: 'show', portfolioChain`
  - `what's my pnl` → `portfolioAction: 'pnl'`
  - `show my portfolio history` → `portfolioAction: 'history'`
- Regex patterns in `parser.ts:103-108`
- Slots: `portfolioAction`, `portfolioChain`

### Portfolio tools
- `aggregatePortfolio(snapshots)` — multi-chain aggregation with chain breakdown
- `calculatePnl(currentValue, costBasis)` — bigint P&L with percentage
- `fetchPortfolio` / `fetchMultiChainPortfolio` — mock portfolio fetcher
- Types: `PortfolioSnapshot`, `PortfolioToken`, `PortfolioPosition`, `PortfolioDeps`

### Tests
- `packages/core/src/index.test.ts` — 4 PORTFOLIO parser tests
- `packages/tools/src/portfolio/aggregator.test.ts` — 2 aggregator tests
- `packages/tools/src/portfolio/pnl.test.ts` — 3 P&L tests

## Integration notes
- Portfolio is read-only — no new transaction surface
- Uses existing chain infrastructure for RPC calls
- P&L uses bigint math to avoid floating-point precision issues
