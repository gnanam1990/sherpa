# Stage 3 P4: TIP + POLL Intents

**Date:** 2026-05-15

## What was built
- TIP intent parser (3 regex patterns: dollar amount, USDC asset, farcaster send)
- POLL intent parser (2 regex patterns: create poll, simple poll)
- TIP planning in executor (ERC-20 transfer to Farcaster-verified address)
- POLL planning in executor (off-chain Farcaster cast)
- Recipient resolution via Neynar API
- Parsing tests for both intents

## Key files
- packages/core/src/parser.ts (TIP_RE, TIP_USER_RE, TIP_USDC_RE, POLL_RE, POLL_SIMPLE_RE)
- packages/core/src/types.ts (TipPlan, PollPlan)
- packages/core/src/executor.ts (planTip, planPoll)
- packages/core/src/index.test.ts (TIP + POLL parsing tests)
