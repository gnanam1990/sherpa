# Devlog: Stage 7 P1 — Governance

**Date:** 2026-05-15
**Stage:** 7 P1
**Author:** Sherpa

## What shipped

### Parser (core)
- `GOVERNANCE` intent with deterministic parsing for:
  - `vote yes on proposal #1` → `govAction: 'vote', govVote, govProposalId`
  - `cast my vote for proposal 5` → `govAction: 'vote', govVote: 'yes'`
  - `vote against proposal 3` → `govAction: 'vote', govVote: 'no'`
  - `create proposal <text>` → `govAction: 'propose'`
  - `delegate my votes to <addr>` → `govAction: 'delegate'`
  - `list active proposals` → `govAction: 'list'`
- Regex patterns in `parser.ts:115-118`
- Slots: `govAction`, `govVote`, `govProposalId`, `govProposalText`, `govDelegatee`

### Governance tools
- `listProposals(deps)` — returns mock proposal list (hardcoded for V1)
- `buildVoteCall(params)` — returns EIP-5792 call object for voting
- `buildDelegateCall(delegatee)` — returns EIP-5792 call object for delegation
- Governor ABI: `castVote`, `propose`, `delegate`
- Types: `ProposalMetadata`, `VoteParams`, `DelegateParams`, `GovernanceDeps`

### Tests
